# S&P500 Stock Prediction using XGBoost

## Project Overview

This project focuses on predicting stock prices for S&P 500 companies using Machine Learning and Time Series Analysis techniques.

The project uses historical stock market data collected over a 10-year period (2015–2025) and applies XGBoost-based forecasting models to analyze trends and predict future stock behavior.


## Dataset

* Dataset: S&P 500 Stocks Historical Data
* Time Period: 2015 – 2025
* Data Type: Daily OHLCV Stock Data
* Source: Kaggle Dataset
Dataset Link: https://www.kaggle.com/datasets/innacampo/s-and-p-500-stocks-daily-historical-data-10-years
